# 🤖 Jarvis AI – Voice Assistant

## 📌 Project Description

Jarvis AI is a Python-based **voice-controlled personal assistant** that performs various tasks using speech recognition and text-to-speech technology.  
The assistant can interact with users through voice commands to search the web, fetch information, play media, send emails, read news, and provide movie details using the IMDb database.

The project integrates multiple Python libraries to deliver a hands-free, interactive assistant experience similar to virtual assistants like Alexa or Google Assistant.

---

## 🚀 Features

- Voice-based interaction using speech recognition
- Text-to-speech responses with a natural voice
- Hotkey-controlled listening mode (start/stop)
- Google and Wikipedia search
- YouTube video search and playback
- Fetch and display current IP address
- Send emails via voice commands
- Read latest news headlines
- Movie information lookup using IMDb API
- Time-based greeting (Morning, Afternoon, Evening)
- Graceful handling of unrecognized speech

---

## 🛠 Tech Stack

- Python  
- SpeechRecognition  
- Pyttsx3 (Text-to-Speech)  
- IMDbPy  
- Keyboard  
- Webbrowser  
- Requests  
- Environment Variables (python-decouple)
